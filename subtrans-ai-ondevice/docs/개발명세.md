# SubTrans AI · On-device Lab 개발 명세 0.3

## 목표와 결정

기존 API 기반 `subtrans-ai`를 보존하고, 별도의 Manifest V3 확장프로그램에서 Chrome 내장 AI의 현실적인 도달 범위를 실험한다. 모든 음성 언어를 Gemini Nano로 곧바로 한국어로 번역하는 방식은 현재 공식 지원 언어와 GPU 제약 때문에 채택하지 않는다.

## 파이프라인

- **기본:** HTML5 영상의 TextTrack(EN/JA/ZH) → 확장 콘텐츠 스크립트 → Offscreen Document의 Translator API → 한국어 Shadow DOM 오버레이.
- **실험:** 현재 탭 오디오 → `tabCapture` → Offscreen Document의 AudioWorklet(16kHz PCM) → 약 4초/무음 구간 분할(강제 분할 시 0.7초 겹침) → Prompt API Gemini Nano 오디오 전사(EN/JA) → 반복 전사 앞부분 제거 → Translator API(→KO) → 오버레이. 무음으로 끝난 구간은 겹치지 않는다.
- 사용자 명시적 시작, 단일 탭 세션, 큐 최대 2개. 오래된 자막 텍스트(20초)와 음성(90초)을 건너뛴다. 탭 이동·종료 시 세션을 정리한다.
- 사용자가 실제 내장 모델 응답을 확인할 수 있도록 확장 전용 실험 페이지를 제공한다. 텍스트 Translator 응답과 짧은 음성 파일의 Nano 전사→Translator 응답을 표시한다. `create()`는 해당 페이지의 사용자 클릭에서 직접 시작한다.

## 보안과 비용

API 키 입력 UI, 외부 API 호스트 권한, 원격 호출 코드를 두지 않는다. CSP의 `connect-src 'none'`으로 확장 페이지의 네트워크 연결을 차단한다. Chrome의 모델 최초 다운로드는 브라우저가 관리한다. 원본 음성·자막 텍스트는 확장 저장소에 기록하지 않는다. 스타일과 세션 상태만 Chrome 저장소에 보관한다.

## 명시적 기능 경계

기본 모드는 접근 가능한 네이티브 TextTrack을 가진 영상만 대상으로 한다. 자막 출력은 두 모드 모두 Shadow DOM 오버레이이며, 음성 모드는 `<video>` 요소가 없는 탭도 화면 전체 기준으로 표시한다. 영상 요소 자체의 전체화면에서는 브라우저 제약에 맞춰 native TextTrack 표시를 사용한다. 별도 iframe/오버레이를 추가해도 접근할 수 없는 커스텀 자막 텍스트나 DRM이 해제되지는 않는다. 음성 모드는 장치·Chrome 버전별 `LanguageModel.availability()`가 `unavailable`이면 실행하지 않는다. 현재 Prompt API가 문서화한 언어 목록에는 KO/ZH가 없으므로 음성 모드의 ZH→KO는 제공하지 않는다. 실제 모델 추론의 지연·품질·호환성은 사용자 장치에서 확인해야 한다.

Chrome 138 이상에서는 Translator API와 확장용 Prompt API를 사용하기 위해 별도 `chrome://flags` 항목을 필수로 켜지 않는다. 모델 다운로드·GPU·저장 공간 조건은 기능 지원과 별개로 검사하고, 팝업/실험실의 실제 응답으로 확인한다.

다음 단계는 사용자 PC의 실제 가용성 측정, 영어/일본어 실음성 정확도·지연 측정, 사이트별 자막 추출 확장, 중국어 온디바이스 음성 경로 조사이다.
