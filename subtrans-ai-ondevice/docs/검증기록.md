# On-device Lab 검증 기록

기준일: 2026-09-27 · 버전: 0.4.0

- 단위 테스트 5개 통과: 지원 언어 제한, 빈 음성 응답, 오디오 구간/WAV 구조, 강제 분할의 겹침/무음 경계, 전사 문구 중복 제거.
- 구문·Manifest·CSP 검사 통과: 원격 API 호스트 권한 없음, 확장 페이지 `connect-src 'none'`.
- Chrome 통합 검사 13개 통과: 독립 확장 로드, 모델 준비 버튼, 팝업의 응답 표시, 전체 화면 실험실의 텍스트·Nano 단독 준비·음성 응답 표시, HTML5 TextTrack 감지와 한국어 오버레이, 중지 후 원상 복구, 실제 `tabCapture` 오디오 입력, AudioWorklet/WAV→Nano 응답→번역 흐름, 한국어 로컬 음성 인식→영·일 번역 경로, `<video>` 없는 페이지의 음성 자막 오버레이, 브라우저 JavaScript 오류 0건.
- 통합 검사는 `Translator`와 `LanguageModel`을 **테스트용 가짜 구현**으로 대체했습니다. 따라서 확장 안에서의 실제 모델 응답, 실음성 전사 품질과 사용자 장치의 Prompt API 오디오 지원 여부는 미검증입니다.
- 별도 실모델 확인: Chrome for Testing 151 임시 프로필에서 `Translator`와 `LanguageModel` API는 노출됨. EN/JA/ZH→KO는 `downloadable`, Nano 오디오 EN/JA는 헤드리스에서 `unavailable`로 보고됨. 영어→한국어 실제 `Translator.create()`를 사용자 클릭으로 시작했으나 헤드리스·일반 창 모드 모두 120초 안에 모델 다운로드나 번역 결과가 나오지 않음. 원인은 이 시험 환경에서 확정하지 못함. 일반 Chrome 153의 실제 결과를 대변하지 않음. 상세 JSON은 `test-results/real-chrome-availability.json`과 `test-results/real-translation.json`.
- 검증 실패 원인 분석: Playwright 기본 실행 옵션에 모델 다운로드 경로에 영향을 주는 `--disable-component-update`, `--disable-background-networking`, `Translate` 기능 비활성화가 포함되어 있었고, 시험 터미널의 기본 격리 환경은 외부 네트워크 소켓을 막았다. 이 상태의 시간 초과는 제품 기능 실패의 증거가 아니었다. 설치된 **Chrome 153**을 일반 시작 옵션으로 실행하고 시험 환경의 네트워크 접근을 허용한 뒤, 별도 임시 프로필에서 실제 언어팩 진행률 7→26→50→73→74→100%를 관찰했다. 실제 `Translator`가 `Good morning.`을 `좋은 아침입니다.`로 번역했다(13.3초). 결과는 `test-results/system-real-translation.json`. Chrome for Testing 151의 별도 시험은 여전히 시간 초과했으며 해당 빌드의 구체적 원인은 단정하지 않는다.
- Chrome 153에서는 예전 명령행 로드 대신 CDP `Extensions.loadUnpacked`로 실제 배포 확장을 임시 프로필에 로드했다. 팝업과 서비스 워커가 실행됐고 `Translator`/`LanguageModel`의 실제 지원 상태를 읽었다. 음성 모델은 `downloadable`/`downloading`으로 표시됐으며, 웹페이지에서 5분간 실제 다운로드를 진행해 68%를 관찰했으나 준비는 완료되지 않았다. 초기 시험 기록은 `test-results/cdp-extension.json`, `test-results/speech-availability.json`.
- 실제 YouTube 확인: 영어 [Jev Explained: Demos and Use Cases](https://www.youtube.com/watch?v=QbYBRjOaGOo&t=13s)는 영상 시각 약 0→40.58초, 일본어 [ドラマ「おいしいのつくりかた」６０秒予告【公式】](https://www.youtube.com/watch?v=p6kpxWGa8AM)는 약 0→40.82초 재생했다. 두 페이지 모두 HTML5 `TextTrack` 0개였다. 확장 오디오 모드 `START` 성공, 재생 중 `<video>`의 `paused=false`, `readyState=4`, Shadow DOM 오버레이 존재를 확인했다. 종료 시 모델 다운로드 상태는 각각 1%였고 번역 결과는 **0개**였다. 그러므로 두 영상의 한국어 자막 정확도·지연 시간은 측정할 수 없었다. 결과 JSON은 `test-results/live-youtube-results.json`, 종료 화면은 `test-results/live-youtube-en-end.png`, `test-results/live-youtube-ja-end.png`.
- 다운로드가 시험용 300초 제한을 초과하는 것을 확인해 Gemini Nano 모델 준비 제한을 20분으로 늘렸다. 모델 다운로드 성공과 실제 음성 전사까지는 추가 검증 대상이다.
- 검사 원본은 `test-results/browser-results.json`에 저장됩니다. 테스트용 확장 복사본에만 로컬 시험 페이지 호스트 권한을 추가하며, 배포 `dist`에는 포함하지 않습니다.
