# SubTrans AI 검증 기록

기준일: 2026-09-26 · 대상: API 전용 초기 구현 (`0.1.0`)

## 자동 검증

- 단위 테스트 18개 통과: 오디오 구간 처리, 공급자 응답 변환, 자막 내보내기 등의 핵심 로직.
- Chrome 통합 검사 15개 통과: 실제 `tabCapture`와 Offscreen Document로 생성한 시험 음성을 캡처하고, OpenAI 전사→번역 및 Gemini 오디오→자막 흐름을 각각 모의 API 응답으로 확인.
- 팝업의 키 저장·비표시, 스타일 실시간 저장, 비디오 전체화면 자막, 일시정지 시 이전 요청 취소, 중지 시 캡처·오버레이 정리, 429 오류 시 자동 중지, 키 삭제, 웹페이지의 키 접근 차단과 위조 메시지 거부를 검사.
- 브라우저 JavaScript 오류 0건. 확장 파일의 구문과 Manifest/CSP 정적 검사 통과.

재현 명령은 프로젝트 폴더에서 `npm test`, `npm run check`, `node scripts/browser-test.mjs`, `npm run build` 순서로 실행한다. 브라우저 통합 검사에는 Chrome for Testing과 Playwright가 필요하며, 상세 결과는 `test-results/browser-results.json`에 기록된다. 테스트 환경에 Playwright가 번들로 제공될 때는 `SUBTRANS_PLAYWRIGHT` 환경 변수로 그 설치 경로를 지정할 수 있다.

## 실제 서비스에서 추가 확인할 항목

실제 사용자 API 키로 OpenAI·Gemini에 유료 요청을 보내지는 않았다. 따라서 현재 모델의 계정별 접근 권한, 실제 요금, 언어별 품질 및 응답 지연은 검증 전이다. 영·중·일 실제 영상으로 짧게 시험하고 오류·요금·자막 동기화를 확인해야 한다. 일부 OTT, iframe, PiP 및 보호된 콘텐츠는 사이트별 제약이 남아 있다. 이 초기 버전은 발화 시작부터 2초 이내 자막 표시나 모든 사이트 지원을 보장하지 않는다.
