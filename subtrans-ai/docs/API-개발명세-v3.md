# SubTrans AI v3 — API 전용 초기 구현

2026-09-26 사용자 결정에 따라 v2의 로컬 STT·로컬 MT·Windows 동반 앱은 현재 범위에서 제외한다. v2는 조사 기록으로 보존한다.

## 핵심 흐름

사용자 API 키 1개 → 확장 내부 공급자 자동 감지 → 현재 탭 캡처 → 짧은 발화 구간 → 해당 공급자만 호출 → 한국어 자막.

OpenAI는 전사와 번역을 분리하고, Gemini는 하나의 오디오 이해 요청에서 원문과 한국어를 함께 반환한다. 모델 ID는 `extension/lib/config.js`에 고정하고 공급자별 JSON 스키마·thinking 옵션은 어댑터가 처리한다.

## 구조 결정

- Chrome 116 이상, Manifest V3. 브라우저 네이티브 ES Modules와 HTML/CSS 사용.
- 서비스 워커는 권한·설정·세션·자막 전달만 담당. 오디오와 HTTP 요청은 Offscreen Document가 소유.
- AudioWorklet에서 mono 16kHz 변환. 20ms 프레임으로 에너지 감지. 무음 600ms 또는 설정한 최대 길이에서 WAV 확정.
- 요청 처리는 직렬. 대기 큐 최대 2개, 오래된 구간 12초 상한, 요청 전체 timeout 20초.
- 각 재생 불연속은 generation 증가, in-flight AbortController 취소, 문맥/큐 초기화. 동일 세대 결과만 표시.
- API 키 기본 세션 보관. 사용자가 선택한 경우에만 기기에 보관. 모든 저장소는 TRUSTED_CONTEXTS로 제한.
- 웹페이지는 API 키·임의 네트워크 기능에 접근 불가. 콘텐츠 메시지는 해당 탭/frame의 재생정보·위치 변경만 허용.
- 기본 30분 사용 제한. 실제 금액 상한, 공급자별 사용 토큰 집계는 후속 작업.

## 제공 UI

팝업: 키 입력, 공급자 자동 감지, 언어/품질 선택, 시작/중지, 상태와 요청 수.

설정: 연결 확인, 키 기억/삭제, 실시간 스타일·미리보기·위치 드래그, 언어·민감도·최대 구간·사용 시간·용어집, 최근 연속 구간 SRT.

## 후속 개발 우선순위

1. 사용자 키로 영·중·일 실영상 평가와 모델 접근성 검증.
2. 단어 절단·배경 음악 오류 측정 후 세그먼트 경계 개선 및 신경망 VAD 검토.
3. 네이티브 라이브 전사 어댑터를 별도 모드로 추가해 지연·요금 비교.
4. 사이트별 iframe·기존 자막 우선·PiP 어댑터와 확장 스토어 배포 준비.

위 후속 항목은 구현 완료 기능과 구분한다. 초기 버전은 모든 사이트 호환 또는 2초 미만 지연을 보장하지 않는다.
