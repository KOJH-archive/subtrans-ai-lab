# SubTrans AI 설치하기

이 버전은 **GPT 또는 Gemini API 키 하나**로 작동합니다. 로컬 모델이나 별도 서버 설치는 필요하지 않습니다.

## 1. 확장프로그램 설치

Chrome 주소창에 아래 주소를 직접 입력합니다.

```text
chrome://extensions
```

오른쪽 위 **개발자 모드**를 켜고 **압축해제된 확장 프로그램을 로드합니다**를 누릅니다. 아래 폴더를 선택합니다.

```text
C:\Users\jongh\Downloads\# CODEX\1차\subtrans-ai\dist
```

ZIP 파일을 다른 위치에 풀었다면 그 안에서 `manifest.json`이 있는 폴더를 선택하면 됩니다. Chrome 도구모음의 퍼즐 아이콘에서 SubTrans AI를 고정하면 편리합니다.

## 2. 키 연결하고 시작

1. 자막을 보고 싶은 동영상 페이지를 열고 재생합니다.
2. SubTrans AI 아이콘을 누릅니다.
3. OpenAI 또는 Gemini API 키를 입력합니다. 키 종류와 기본 모델은 자동 선택됩니다.
4. **현재 탭 번역 시작**을 누릅니다. 팝업을 닫아도 번역은 계속됩니다.

키는 채팅에 보내지 말고 확장 설정에 직접 입력하세요. 기본적으로 브라우저 종료 시 키가 삭제됩니다. 계속 사용하려면 **이 브라우저에 키 기억하기**를 켤 수 있습니다.

키 발급: [OpenAI](https://platform.openai.com/api-keys), [Google AI Studio](https://aistudio.google.com/apikey). API 사용 권한·할당량이 필요하며 API 요금은 본인 계정에 청구됩니다.

## 3. 원하는 자막으로 조정

팝업의 **자막 스타일 · 상세 설정**을 누르면 글자 크기, 폰트, 색상, 배경, 위치, 원문 표시, 용어집을 바꿀 수 있습니다. 자막 스타일은 번역 중에도 바로 적용됩니다.

기본 설정은 가성비 모드, 최대 3.6초 음성 구간, 30분 후 자동 중지입니다. 긴 영상은 자동 중지 시간을 늘리거나 다시 시작하세요.

## 사용 전 알아둘 점

- 선택한 API에 현재 탭의 오디오와 번역 문맥이 전송됩니다.
- 초기 버전은 짧은 음성 구간을 모아 처리하므로 수 초의 지연이 있습니다.
- 화면의 처리 지연은 **구간 수집 완료 이후**의 시간이며, 발화 시작부터의 전체 지연은 더 깁니다.
- 일반 웹 동영상 중심으로 구현했습니다. 일부 OTT, iframe, PiP는 제한이 있습니다.
- 실제 API 키를 이용한 번역 품질·청구 테스트는 아직 수행하지 않았습니다. 첫 사용은 짧은 영상으로 확인하세요.
